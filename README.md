## ✨ Features

This boilerplate comes packed with features to kickstart your next Flutter project:

- **State Management**: Clean, scalable state management using `flutter_bloc` / `cubit`.
- **Authentication**: Robust authentication flow with Firebase.
  - [x] Email & Password (Sign Up, Sign In)
  - [x] Google Sign-In
  - [x] Password Reset
  - [x] Animated Login/Signup UI with **Rive**

- **Backend & Database**: Integrated with **Firebase** services.
  - [x] **Cloud Firestore** for data storage.
  - [x] **Firebase Messaging** for Push Notifications.

- **Cross-Platform**: Single codebase for **Android, iOS, Web, Windows, macOS, and Linux**.

- **UI & Theming**:
  - [x] Onboarding screens with a carousel slider.
  - [x] Centralized theme and color management.
  - [x] Reusable core widgets for consistency.
  - [x] Offline/Online connection handling UI.
  - [x] Launcher icon generation via `flutter_launcher_icons`.

- **Device & Native Features**:
  - [x] **Maps & Geolocation**: `flutter_map`, `geolocator`, and `geocoding`.
  - [x] **Camera**: Integrated camera functionality.
  - [x] **Local Notifications**: Using `flutter_local_notifications`.
  - [x] **Webviews**: In-app browsing with `webview_flutter`.

- **Modern Architecture**:
  - [x] **Centralized Routing**: Named routes managed by `AppRouter`.
  - [x] **Dependency Management**: Sensible use of `provider` for dependency injection.
  - [x] **Helper & Extensions**: Utility classes to keep code DRY.
  - [x] **Localization**: Ready for internationalization with `flutter_localization`.

## 🚀 Getting Started

Follow these instructions to get the project up and running on your local machine.

### Prerequisites

- Flutter SDK (version >=3.4.0)
- An IDE like VS Code or Android Studio
- FlutterFire CLI

### Installation & Setup

1.  **Clone the repository:**
    ```sh
    git clone <your-repository-url>
    cd auth_bloc
    ```

2.  **Set up Firebase:**
    This project is configured to use Firebase. You'll need to connect it to your own Firebase project.

    - Create a new project on the Firebase Console.
    - Run the FlutterFire configuration command to automatically generate your platform-specific configuration:
      ```sh
      flutterfire configure
      ```
    - This will create `lib/firebase_options.dart` and configure the native platforms. For Android, it will also download the `google-services.json` file.
    - **Enable Authentication Methods**: In the Firebase console, go to `Authentication > Sign-in method` and enable **Email/Password** and **Google**.
    - **Set up Firestore**: In the Firebase console, go to `Firestore Database` and create a database.

3.  **Install dependencies:**
    ```sh
    flutter pub get
    ```

4.  **Generate Launcher Icons (Optional):**
    If you've changed the icon at `assets/icon/icon.png`, run this command to update the launcher icons for all platforms.
    ```sh
    flutter pub run flutter_launcher_icons
    ```

5.  **Run the app:**
    ```sh
    flutter run
    ```

## 📂 Project Structure

The `lib` folder is structured to promote separation of concerns and scalability.

```
lib
├── core/         # Core widgets and utilities
├── helpers/      # App-wide helpers, extensions, and constants
├── logic/        # Business logic (BLoCs/Cubits)
├── routing/      # Navigation and route management
├── screens/      # UI for each screen/feature
├── theming/      # App-wide colors, styles, and themes
├── firebase_options.dart # Generated by FlutterFire
└── main.dart     # App entry point
```
